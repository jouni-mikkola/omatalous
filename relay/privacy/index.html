Omatalous: tietosuoja

  • Omatalous on kotitalouden oma taloussovellus. Se toimii talouden omalla koneella.
  • Pankkitiedot kulkevat pankista Enable Bankingin kautta vain tälle koneelle.
  • Paluusivu on GitHub Pagesissa. GitHub Pages näkee paluupyynnön kuten mikä tahansa verkkopalvelin: kertakäyttöisen koodin, osoitteen, johon sivu ohjaa selaimen, ja kävijän IP-osoitteen.
  • Sovelluksen kehittäjä ei saa taloudelta mitään tietoja.
  • Jos ylläpitäjä sallii toimialahaun, kauppiaiden yritysnimiä haetaan YTJ:stä. Summia, päiviä, tilinumeroita tai henkilöiden nimiä ei lähetetä.
  • Kysymykset tietojen käsittelystä menevät talouden ylläpitäjälle, joka on rekisteröinyt sovelluksen Enable Bankingissa.
  • Tämä sivu ei aseta evästeitä eikä lataa mitään muualta.

Omatalous: privacy

  • Omatalous is a household's own finance app. It runs on the household's own machine.
  • Bank data goes from the bank through Enable Banking to that machine only.
  • The return page is served by GitHub Pages. It sees the return request like any web host: the one-time code, the local address the page forwards the browser to and the visitor's IP address.
  • The developer of the app receives no data from the household.
  • If the admin allows the merchant industry lookup, the company names of merchants are looked up in YTJ, the Finnish trade register. Amounts, dates, account numbers and names of people are not sent.
  • Questions about the handling of data go to the household's admin, who registered the app with Enable Banking.
  • This page sets no cookies and loads nothing from elsewhere.
