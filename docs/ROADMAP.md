# Roadmap

Omatalous is a self-hosted household finance app for Finland. The work that is planned is in the
GitHub issues of this repository, one issue per change, and each
change is a pull request whose checks run on GitHub. This file keeps what an issue does not: the releases that are
coming, the reviews on the calendar and what is not planned.

The step list this file held until commit 8e5f42345 was the work queue of an external task board. It is in git history
(`git show 8e5f42345:docs/ROADMAP.md`); a step from it that still holds becomes an issue.

## Coming releases

No release after 1.2.2 has a version yet. A release named here moves out of this section when it ships.

## Not planned

- Payments from the app, credit scoring, investment advice, telemetry.
- Asking the home router for addresses.
- Free-text questions to the app.
- A cloud language model.
- Interest rate data bundled in the app.
- Opening data automatically after a period of inactivity.
- A native mobile app.
